# Multi-Force Crime Performance & Macro Trends Dashboard (2019-2024)

## Overview
Developed as part of Rockborne's Data and AI Training Academy, this project delivers a self-serve, operational BI dashboard built for police force leaderships teams.

In addition to the dashboard, a structured presentation was developed specifically for the police force leadership teams to discuss
- How to navigate the dashboard on Power BI
- Key insights derived from the dashboard
- Potential recommendations based on the data presented from the dashboard

The dashboard is designed to be quick to access, intuitive and non-technical to allow leadership to monitor crime performance, track volume drivers and make evidence-based decisions

## Scope & Force Selection
To provide meaningful comparative analysis along a key geographic corridor, the dashboard focuses on four representative police forces spanning the commuter belt across a 5-year period from 2019 to 2024:
* Metropolitan Police
* Surrey Police
* Sussex Police
* Thames Valley Police


## Key Features & Structure
* **Page 1 - Overview:** High-level monitoring and peer comparison tracking total crime volume, crime rates per 1,000 residents, and socio-economic deprivation correlations.
* **Page 2 - Drill-Down / Investigation:** Granular exploration enabling stakeholders to filter data dynamically by year, specific police force, and crime category to investigate seasonal patterns or anomalies.

## Tech Stack & Deliverables
* **Tool:** Power BI / Tableau
* **Deliverables:** Self-serve operational dashboard, executive presentation walkthrough, and stakeholder documentation.
